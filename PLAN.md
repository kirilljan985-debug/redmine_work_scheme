# План проекта Redmine Work Scheme

Живой план: текущее состояние и свободные треки. Выполненные задачи
с результатами и проверками — в `PLAN_HISTORY.md`; точка продолжения —
в конце `AGENTS.md` (читается в каждой новой сессии).

## Правило сопровождения изменений

Любое изменение проекта выполняется вместе с актуализацией плана и файла
памяти `AGENTS.md`: до работы фиксируется задача и критерии готовности,
после работы — фактический результат, тесты, коммит, push и состояние CI.
Если изменение не требует отдельного пункта плана, в плане всё равно
записывается краткая отметка о нём.

## Проверка перед завершением задачи

1. Обновить `PLAN.md` и `AGENTS.md`.
2. Выполнить релевантные локальные проверки и тесты.
3. Проверить `git diff` и `git status`.
4. Создать коммит и отправить его в GitHub.
5. Дождаться зелёного CI или зафиксировать диагностику падения в памяти проекта.

## Результат — 2026-10-28: v0.5.6, просмотр на сенсорном экране

режим с выходом, перемещение увеличенной схемы пальцем, ручное и периодическое
обновление счётчиков (выключено / 30 с / 1 мин / 5 мин) со временем успеха.
Критерии: controls остаются на месте; drag не открывает подсказку, обычный тап
работает; редактор сохраняет своё поведение; вкладки и повторная инициализация

Реализовано: отдельный viewport только в просмотре; auto-fit при открытии,
переключении и resize, ручной zoom до 400%; Fullscreen API с fallback на окно
страницы и выходом по кнопке/Escape; нативный touch-scroll с подавлением клика
после свайпа; ручные/периодические counts, no-store, timeout 15 с, время успеха,
сохранение данных при ошибке, пауза в скрытой вкладке, cleanup при destroy.
Добавлены ru/en-атрибуты и integration-ассерты; dev cache-bust v=107.
Локально: JS smoke 102/102, unit 40/208, Ruby/JS-синтаксис, parity локалей.
Браузер: auto-fit в 420px dashboard, полный экран (fallback IAB), возврат,
прокрутка только полотна, refresh/интервал/вкладки; SVG и overlay совпадают,
консоль без ошибок. Native fullscreen покрыт jsdom; реальный Nextouch пока
не проверен. Коммит/push/CI — следующий шаг; живой сервер не менялся.

## Результат Codex — 2026-10-28: v0.5.5 завершён

Сенсорный патч закоммичен локально в `4192fb8`, smoke 46/46. Продолжение
мульти-схем: используем единый ключ `json` с wrapper
`{"schemes":[{"id":"main","title":"...","json":{...}}, ...]}`.
Это заменяет прежнее решение об `extra_schemes`: стандартное сохранение
настроек перезаписывает хэш. Максимум 10 схем ВСЕГО, общий JSON ≤ 60 КБ.
Основная схема первая, id `main`, не удаляется. Одиночная схема сохраняет
прежний формат. Переключение сохраняет локальные изменения всех вкладок,
сбрасывает проигрывание/выделение/capture и историю Undo/Redo.

Критерии: исправить контракт parse_collection, сохранить legacy-рендер и
страницы этапов; неизвестная схема → 404; viewer/editor вкладки, add/delete,
единое save/download; защита от поздних counts; Ruby unit/integration и
jsdom-регрессии, браузерная проверка, README/handoff/память; push и 5 зелёных CI.
Чужие изменения Zcode приняты в продолжение этой задачи по поручению пользователя.
