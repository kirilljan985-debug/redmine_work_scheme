# План проекта Redmine Work Scheme

Живой план: текущая задача, правила и состояние. Выполненные задачи
с результатами и проверками — в `PLAN_HISTORY.md`.

## Правило сопровождения изменений

Любое изменение проекта выполняется вместе с актуализацией плана и файла
памяти `AGENTS.md`: до работы фиксируется задача и критерии готовности,
после работы — фактический результат, тесты, коммит, push и состояние CI.
Если изменение не требует отдельного пункта плана, в плане всё равно
записывается краткая отметка о нём.

## Проверка перед завершением задачи

1. Обновить `PLAN.md` и `AGENTS.md`.
2. Выполнить релевантные локальные проверки и тесты.
3. Проверить `git diff` и `git status`.
4. Создать коммит и отправить его в GitHub.
5. Дождаться зелёного CI или зафиксировать диагностику падения в памяти проекта.

## Текущая работа — правки третьего ревью «чистое ПО» (2026-10-26)

Задача: довести код до чистого состояния по итогам третьего ревью
(4 суб-агента): 2×P1, ~8×P2, ~15×P3.

Результат: все P1/P2 и выборочно P3 исправлены.
P1: counts переживает Bignum-id (`between?(1, 2**62)` + верхняя граница
query_id 999 999 999 в валидаторе); на странице редактора один View
(init пропускает контейнеры внутри #ws-editor), поздние ответы счётчиков
отцеплённого View не сносят бейджи (guard по self.svg.parentNode).
P2: float-координаты округляются (`int_value` Numeric.round); ресайз ставит
dirty одним снимком на onUp; drag узла возвращает выделение/hit-пути/dirty
через хук `onNodeDragEnd`; поля «Текст на схеме» включены в markFormDirty
(.ws-text-style); мёртвая цепочка add-node/add-edge удалена целиком
(атрибуты, labels, кнопки, addNode, ветка pendingFrom, CSS, ключи локалей);
Ctrl+Z/Y и стрелки не перехватываются в INPUT/TEXTAREA/SELECT; зрительские
строки локализованы (ws_note_no_scenarios, ws_label_tasks, ws_label_progress
через data-label); CI получил timeout-minutes, permissions, concurrency
и node --check на обеих джобах.
P3: переименования message_for/interpolate (не затеняют Kernel#format и не
имитируют I18n), MESSAGES на «стрелку» вместо «связи», текст цвета текста
разведён на ключи узел/стрелка, bounds() учитывает bend дуг (нет обрезки),
no-op таймер удалён, статус «Источник выбран: кликните блок-цель»,
stage-rescue удалён как недостижимый, version 0.3.0, PLAN архивирован в
PLAN_HISTORY.md, AGENTS.md приведён к единственной актуальной точке,
лог-мусор из корня удалён.
Тесты: +7 юнит-кейсов (порядок seen_pairs, дубли сценария, url-грани,
клампы bend/font/float/huge query_id, не-массивы), counts Array-формат и
флуд 150 id, login_required зафиксирован в анонимном тесте.
Проверки: ruby -c, node --check, YAML, standalone-валидатор (округление,
граница query_id, «Стрелка»), аудит локалей (73 ключа, parity, ноль мёртвых),
git diff --check; браузерно v=91 — превью 10 узлов/2 бейджа, undo после
удаления одним Ctrl+Z, dirty-статус. Cache-bust v=91, dev-разметка синхронна
с production-партиалом.

Критерии готовности:

## Текущее состояние

- Реализовано и зелёное в CI: SVG-схема с валидатором, страницы этапов,
  проигрывание сценариев с эффектами, визуальный редактор, 5 тем интерфейса,
  живые счётчики задач, dashboard-блок additionals.
- CI: три джобы (Redmine 7.0-stable, master, 7.0-stable+additionals на
  PostgreSQL) + eager-load smoke check + node --check.
- Осознанные ограничения: интерфейс редактора и тексты валидатора — русские
  (см. README «Ограничения локализации»); терминология «узел/стрелка»
  закреплена, полный словарный унификатор «блок/этап» отложен.
- Свободные треки: полный i18n редактора, bundler-cache в CI, мини-карта
  больших схем, мобильная компоновка, тест рендера dashboard-блока
  (таблицы additionals в CI уже мигрируются).
