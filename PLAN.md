# План проекта Redmine Work Scheme

## Текущая работа — темы перебивались автотьмой системы (2026-10-26)

Задача: блоки и панели должны следовать явно выбранной теме схемы, а не
системному prefers-color-scheme или классам темы Redmine.

Результат: из CSS удалены `@media (prefers-color-scheme: dark)` и блок
`body.theme-dark/body.dark/[data-theme=dark]` — они перебивали переменные
пяти явных тем, из-за чего при Classic на тёмной системе блоки «зависали»
тёмными, а сайдбар становился нечитаемым (светлый текст на светлой стеклянной
панели). Единственный источник стиля — поле `theme` (Graphite = осознанный
тёмный выбор, сохраняется в схеме). Проверено скриншотами в dev-редакторе
v=89 при `systemDark: true`: Classic — блоки rgb(238,244,251), тёмный читаемый
сайдбар; Graphite — блоки rgb(38,61,82), полотно rgb(17,24,32), светлый текст,
статус dirty. Селект тем — нативный, работал всегда, но не влиял на блоки.
Cache-bust поднят до v=89.

## Результат — фиксы по итогам ревью (2026-10-26)

Все находки P0/P1/P2 исправлены. Ключевое: P0 (экранированный JSON в
`<script>` — схема не рисовалась бы на живом Redmine) закрыт выводом через
